# ASCII Type Poster

## 简介

ASCII Type Poster 是一个用于制作 3:4 竖版 ASCII／半色调海报的 Skill。它把图像、主题描述或纯文字排版转化为具有清晰标题、圆点纹理、充足留白和图文融合关系的视觉作品，适合封面、社交媒体海报、活动视觉和概念设计。你只需提供素材、文字与偏好的色彩或氛围；在具备图像生成或编辑能力的 Agent 中，它会完成构图提示与视觉生成。

## 功能

Skill 会根据输入自动选择以下模式：

1. **图像变换**：以用户上传的照片或图片为基础，重组为 ASCII／半色调海报，并保留主体特征。
2. **主题生成**：根据一句或几句主题描述生成主体，再完成标题、纹理和版式设计。
3. **纯文字构成**：没有图片时，以标题、短句和抽象符号建立文字主导的海报。

三种模式都支持指定标题、辅助信息、色彩、氛围、纹理形状和画布比例；未指定的项目会按主体与整体层级适配。

## 安装

### 推荐：选择安装目标

```bash
npx skills add DiqingWWW/ascii-type-poster --global
```

安装器会自动检测本机支持的 Agent，并提示选择安装目标。

### 安装到所有已检测到的 Agent

```bash
npx skills add DiqingWWW/ascii-type-poster --skill ascii-type-poster --agent '*' --global
```

本 Skill 使用通用 `SKILL.md` 规范，可安装到 Codex、Claude Code、Cursor、OpenCode、Gemini CLI、GitHub Copilot、Cline 等兼容 Agent。安装器读取本目录的 `SKILL.md`；`openai.yaml` 仅为 OpenAI/Codex 界面提供可选元数据，不影响其他 Agent 安装。

## 使用方式

直接用自然语言描述目标即可。建议明确写出素材、标题、辅助信息、色彩和氛围；需要严格保留的文字请使用引号。

### 示例一：变换上传图片

> 用 ascii-type-poster 处理这张照片。标题为“春日的颜色”，使用蓝紫色圆点半色调，保留人物轮廓并增加大面积留白。

### 示例二：根据主题生成

> 用 ascii-type-poster 制作一张 3:4 海报，主体是雾中的紫藤花枝，标题为“WISTERIA”，整体安静、轻盈，底部加入一行很小的地点信息。

### 示例三：纯文字海报

> 不使用图片，用 ascii-type-poster 做一张文字主导海报。标题是“CAT WOMAN”，加入圆点和方形纹理，黑白基调，保留宽阔边距。

## 输入说明

- **图片**：上传图片或提供可访问的图片输入。说明希望保留的主体、裁切重点和需要弱化的区域。
- **主题**：用一句话说明主体、场景、情绪、材质或参考风格；越具体，构图越稳定。
- **文字**：提供主标题、可选的支持信息及其位置。引号中的内容应按原文排版，不要让系统自行改写。
- **视觉偏好**：可指定颜色、明暗、圆点大小、纹理密度、对齐方式、留白比例和视觉层级。未指定时由素材与主题决定。
- **输出尺寸**：默认 3:4 竖版；如有发布平台的像素要求，请一并说明。

## 设计行为

- **构图**：默认使用 3:4 竖版画布，先建立明确的主体区域，再安排标题和辅助信息。
- **纹理**：优先使用圆点半色调（halftone）表现明暗和材质；可在用户要求时加入 ASCII 字符、方点或其他规则纹理。
- **留白**：保留可呼吸的边距和负空间，避免主体、标题、支持信息互相挤压。
- **图文融合**：文字不是贴在图片上的独立标签，而是与主体轮廓、纹理密度和视觉动线共同构成版式。
- **标题与支持信息**：标题保持用户提供的准确拼写、大小写和标点；支持信息只在用户要求时加入，默认不擅自添加日期、品牌或说明文字，并通过字号、位置和对比度建立层级。
- **色彩**：用户指定的色彩优先；图像变换模式可从源图提取或协调色；未指定时根据主题氛围选择并控制对比度，保证文字可读。

## 兼容性与能力降级

本 Skill 适用于支持 Agent Skills 格式的 Agent。使用上方统一命令即可选择一个或多个兼容 Agent，无需为 Codex、Claude Code、Cursor、OpenCode 等分别维护安装命令。

如果当前 Agent 没有可用的图像工具，仍会根据输入返回可执行的生成提示词、构图说明、文字层级和参数配方，方便交给其他图像工具完成。若某项能力不支持，可手动指定画布、颜色或纹理来获得更可控的结果。

## 重要限制

- `Image Transform` 默认采用生成式重绘，输出会重新解释细节，不承诺逐像素保真；需要严格像素一致时，应改用确定性图像处理工具或工作流。
- 生成式模型可能出现文字拼写、字符形状或细小辅助信息偏差。对必须准确的文字应检查成品，必要时重试或在后期排版。
- 复杂图片、特殊字体或高密度纹理可能需要多次生成，才能兼顾主体识别、留白与文字可读性。
- 没有图像生成或编辑工具时，本 Skill 只返回 prompt／recipe（提示词与制作配方），不会凭空提供图片文件。
